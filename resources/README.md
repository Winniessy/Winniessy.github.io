# 学习资料 / 官网

这里整理学习过程中经常需要查阅的官方文档、源码仓库和开发工具入口。优先使用官方资料，遇到版本差异时以项目官网和仓库说明为准。

## Linux / 工具链

- [Linux Kernel Archives](https://www.kernel.org/)：Linux 内核源码、版本和补丁。
- [Linux Kernel Documentation](https://docs.kernel.org/)：Linux 内核官方文档。
- [GNU Project](https://www.gnu.org/)：GCC、GDB、Make 等 GNU 工具链项目。
- [GCC](https://gcc.gnu.org/)：GNU C/C++ 编译器。
- [GDB](https://sourceware.org/gdb/)：GNU 调试器。
- [Git](https://git-scm.com/)：版本控制工具官网和官方文档。
- [CMake](https://cmake.org/)：跨平台构建工具。

## MCU / RTOS

- [FreeRTOS](https://www.freertos.org/)：FreeRTOS 官网、文档和入门资料。
- [FreeRTOS Kernel](https://github.com/FreeRTOS/FreeRTOS-Kernel)：FreeRTOS 内核源码仓库。
- [Arm Developer](https://developer.arm.com/)：Arm 架构、Cortex-M 和开发工具资料。
- [CMSIS](https://github.com/ARM-software/CMSIS_5)：Arm 官方 CMSIS 源码仓库。
- [STM32Cube MCU & MPU Packages](https://www.st.com/en/embedded-software/stm32cube-mcu-mpu-packages.html)：ST 官方 STM32Cube 软件包入口。
- [STM32 Developer Zone](https://www.st.com/content/st_com/en/stm32-mcu-developer-zone.html)：ST 官方 STM32 开发资料。
- [ESP-IDF Programming Guide](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/)：Espressif 官方 ESP-IDF 文档。
- [ESP-IDF](https://github.com/espressif/esp-idf)：Espressif 官方 ESP-IDF 源码仓库。
- [Zephyr Documentation](https://docs.zephyrproject.org/latest/)：Zephyr 官方文档。
- [Zephyr](https://github.com/zephyrproject-rtos/zephyr)：Zephyr RTOS 源码仓库。
- [RT-Thread](https://www.rt-thread.org/)：RT-Thread 官网、文档和社区入口。

## 查阅建议

1. 先看项目官网的入门文档，确认基本概念和适用版本。
2. 遇到 API 或配置问题，再查看对应版本的官方文档。
3. 需要理解实现细节时，进入官方源码仓库搜索代码和提交记录。
4. 不同芯片厂商的配置方式可能不同，最终以芯片手册和官方软件包为准。
